# Manual Typing & Code Presentation Format Rule

When writing or presenting code for the user (for existing projects or brand new projects):
1. Always specify the exact file path and folder/sub-folder structure clearly (e.g. `src/components/Header.jsx`).
2. Present code line-by-line or in small, easy-to-read, logically separated blocks.
3. Include line-by-line comments/annotations so the user can easily look at the screen and type the code manually onto another computer step-by-step.
